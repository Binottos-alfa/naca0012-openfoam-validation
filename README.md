# naca0012-openfoam-validation
2D RANS validation of the NACA 0012 airfoil with OpenFOAM against NASA data
## Environment

| Component | Version |
| --- | --- |
| OS | Windows 11 + WSL2, Ubuntu 26.04.1 LTS |
| OpenFOAM | v2606 (openfoam.com) |
| ParaView | 6.2.0 (Windows) |
| Hardware | 32 logical cores, 15 GiB RAM available to WSL |
